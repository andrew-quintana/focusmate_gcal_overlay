FocusMate Calendar Extension

Configure your extension settings

Overlay Settings

When enabled, your Google Calendar events will be displayed as an overlay on the Focusmate page.

Calendar Selection

Loading calendars...

Select one or more calendars to display in the overlay. Calendars are organized by account and group.

Conflict Highlighting

Color used to highlight Focusmate sessions that conflict with Google Calendar events. Use hex format (#rrggbb) or CSS color names.

Focusmate API (Optional)

Optional. If provided, the extension will use the Focusmate API to fetch sessions. If not provided, sessions will be detected from the DOM or Google Calendar (when sync is enabled).

Debug Settings

When enabled, detailed debug information will be logged to the browser console. Useful for troubleshooting.
